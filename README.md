# Persistent Agent

一个可逐步扩展的持久化角色 Agent 项目。

目标是将运行时、模型接入、长期记忆、工具和执行环境分离，
并为身份、关系状态及未来的交互方式保留扩展空间。

## 当前状态

已创建项目目录骨架，尚未实现可运行功能。

## V0.1 目标

- 支持命令行对话
- 对接一个大语言模型 API
- 跑通工具调用循环
- 实现长期记忆的保存、检索与上下文注入
- 将运行数据保存在本地

## 目录

- docs/：设计文档
- src/persistent_agent/：程序源代码
- tests/：测试代码
- data/：本地运行数据，不提交到 Git
- workspace/：Agent 工作目录，不提交到 Git
