## 2. 项目目标与实施原则

### 长期目标

构建具备环境、模型、工具、记忆和 Harness（负责组织模型调用、上下文与工具执行的程序框架）的 Agent，为以后增加桌面 2D 形象、身份、关系和状态管理保留接口。

### V0.1 目标

- 命令行交互与一个模型供应商接入。
- 当前会话历史与上下文构建。
- 工具注册、执行、结果返回模型的完整循环。
- 长期记忆保存、检索及上下文注入。
- 运行数据在本地持久化。

### 已确定的边界

1. LLM 不等于记忆：长期 Memory 应独立于具体模型供应商。
2. Runtime 负责协调，各模块实现自己的职责。
3. 当前会话历史与跨重启长期记忆分开管理。
4. 目录和空文件只代表规划，不代表实现完成。
5. 实现按阶段推进，不一次填满所有预留模块。
6. `workspace/` 只是约定目录；访问限制需要代码实现。
